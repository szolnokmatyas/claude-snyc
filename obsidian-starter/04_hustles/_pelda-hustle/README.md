# Példa hustle-mappa

Másold ezt a mappát minden új bevételi forráshoz, és nevezd át
(ASCII, kisbetű, kötőjel — pl. `webshop`, `konzultacio`, `print-on-demand`).

Egy hustle-mappa tartalma:

```
<nev>/
├── index.md        <- a _templates/hustle.md alapján, EZ a belépési pont
├── penzugyek.md    <- bevétel/kiadás, ha van
├── anyagok/        <- vázlatok, szövegek, képek
└── naplo.md        <- mi történt, mikor
```

Csak az `index.md` kötelező. A többit akkor hozd létre, amikor tényleg kell —
üres mappákkal nem tartunk rendet, csak látszatot.
